## SecurePass
Ваши пароли — это ключи к цифровой жизни. SecurePass помогает генерировать сложные, уникальные пароли для всех ваших аккаунтов, защищая вас от взломов и утечек данных.

### Возможности:
- Ввод мастер пароля для входа в приложение
- Сохранение паролей
- Генерация сверхнадежных паролей с настраиваемой длиной и символами
- Быстрое копирование в буфер обмена
- Контроль сложности (цифры, спецсимволы, заглавные буквы)
- Темный режим для комфортного использования ночью
- Без интернета — работает полностью оффлайн
